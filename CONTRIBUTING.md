# Contributing to FotoBeat Desktop

Thanks for your interest in contributing to **FotoBeat Desktop**! This project aims to provide an offline‑first video‑editing experience using JavaScript/Electron. We welcome contributions of all kinds—not only code.

## How to contribute

1. **Fork** the repository and create a new branch (`git checkout -b feature/my-feature`).
2. Make your changes, following the existing code style. Use the provided scripts to set up the project:

   ```bash
   npm install
   npm run dev
   ```
   For the Electron shell, see the README for specific commands.

3. **Commit** your changes with clear commit messages.
4. **Push** to your fork and open a **pull request** against `main`.
5. We will review your PR and may request changes or suggest improvements.

## Guidelines

- Follow the [Contributor Covenant Code of Conduct](./CODE_OF_CONDUCT.md).
- Keep documentation up to date. If you add or change features, update README files.
- Be respectful in issues and pull requests. Provide clear descriptions of bugs or feature proposals.
- For small improvements (e.g. fixing typos or adding tests), feel free to open a PR directly.
- You can also contribute by writing documentation, improving translations, triaging issues or helping with testing.

Thank you for helping make FotoBeat better!
