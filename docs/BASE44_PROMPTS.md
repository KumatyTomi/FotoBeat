# Prompty Base44 dla FotoBeat.me

## Prompt główny — aplikacja

Zbuduj aplikację FotoBeat.me: kreator krótkich filmów ze zdjęć i muzyki. Interfejs ma mieć dwa główne pola uploadu: pierwsze dla plików graficznych, drugie dla pliku audio MP3/WAV. Aplikacja ma automatycznie wyselekcjonować zdjęcia z wrzuconego zbioru, dobrać kolejność, dopasować przejścia i efekty do rytmu muzyki, a następnie pokazać timeline filmu.

Styl: ciemny, nowoczesny, cyberpunk/neon, glassmorphism, gradient fiolet-cyjan, dynamiczny vibe. Bez zbędnej korporacyjności. Produkt ma wyglądać jak narzędzie kreatywne do robienia teledysków ze zdjęć.

## Prompt — editor

Stwórz ekran edytora projektu FotoBeat.me:
- upload zdjęć,
- upload audio,
- wybór formatu 16:9 / 9:16 / 1:1,
- wybór presetu efektów,
- timeline z klipami,
- przycisk renderowania,
- panel podglądu filmu,
- autosave status.

## Prompt — efekty

Dodaj bibliotekę efektów:
- Neon Pulse,
- Smoke Cut,
- Matrix Glitch,
- Sin City,
- Cyberpunk Flash,
- Dark Loft,
- Spiral Zoom,
- Dream Fade.

Każdy efekt powinien mieć opis, intensywność i sugerowane użycie na intro/drop/outro.

## Prompt — render flow

Dodaj stan renderowania:
- queued,
- analyzing audio,
- selecting photos,
- building timeline,
- rendering,
- ready,
- failed.

Pokaż pasek postępu oraz komunikaty przyjazne użytkownikowi.
