# FotoBeat Desktop build hygiene

## Status

Desktop build tooling is now pinned instead of using `latest`.

```json
{
  "electron": "41.2.1",
  "electron-builder": "24.13.3"
}
```

This avoids silent changes in Electron or electron-builder between installs.

## Install workflow

Root renderer:

```bash
npm install
npm run build
```

Desktop wrapper:

```bash
cd desktop
npm install
npm run pack
```

Windows development shell:

```bash
cd desktop
npm run dev:win
```

Unix/macOS development shell:

```bash
cd desktop
npm run dev
```

## Lockfile rule

The repository now has `.npmrc` with:

```text
save-exact=true
fund=false
audit=false
```

After running `npm install` in both root and `desktop/`, commit generated lockfiles:

```text
package-lock.json
desktop/package-lock.json
```

Do not hand-write lockfiles. They must be generated by npm.

## Build script changes

`desktop/package.json` now builds the Vite renderer before packaging:

```bash
npm run build:web && electron-builder --dir
npm run build:web && electron-builder
```

This keeps `desktop/build.extraResources.from = ../dist` valid before packaging.
