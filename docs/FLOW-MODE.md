# Flow Mode — Tryb Głębokiej Pracy w FotoBeat

**Cel:** Maksymalna ochrona kreatywnego flow podczas edycji.

## Kluczowe funkcje

- Ukrywa wszystkie boczne panele
- Powiększa obszar preview + timeline
- Zapamiętuje dokładny kontekst sesji (czas, zoom, zaznaczenie)
- Floating bar z minutnikiem
- Klawisz: `Ctrl + Shift + F`
- Automatyczne snapshoty co 45 sekund
