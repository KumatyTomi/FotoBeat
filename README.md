## Kluczowe cechy

- W pełni lokalny (local-first)
- Analiza beatów i inteligentny timeline
- Eksport sekwencji klatek + MP4
- Electron + droga do natywnego FFmpeg
- Flow Mode • Multi-project workspace (w budowie)

## Szybki start

```bash
git clone https://github.com/KumatyTomi/FotoBeat.git
cd FotoBeat
npm install && npm run dev
```

## Flow Mode (Deep Work)

Tryb pełnego skupienia. Ukrywa rozpraszacze, powiększa canvas + timeline, zapamiętuje kontekst sesji i chroni kreatywny flow.
